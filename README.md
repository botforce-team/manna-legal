# Manna – Rechtliche Seiten

Datenschutzerklärung und Support-Seite für die iOS-App
**Manna – Bibel für den Alltag** (BOTFORCE GmbH).

- [Datenschutzerklärung](https://botforce-team.github.io/manna-legal/datenschutz.html)
- [Support](https://botforce-team.github.io/manna-legal/support.html)

Diese Seiten werden aus `legal/datenschutz-de.md` im (privaten) App-Repository
generiert — `tools/build-legal-pages.py`. Änderungen gehören dorthin, nicht hierher.

Jede Seite ist eine einzelne Datei ohne externe Anfragen: keine Schriftart von
einem CDN, keine Analyse, kein Zählpixel. Eine Datenschutzerklärung, die selbst
nach Hause telefoniert, wäre ihre eigene Pointe.
